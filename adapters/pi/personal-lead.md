# Pi personal lead

## Role

Lightweight personal auxiliary harness for exploration, repository tasks, and workflow execution when a full OpenCode session is unnecessary.

## Route

- Default model: `personal-worker`.
- Explicit planning/review selection: `personal-planner` and `personal-reviewer`.

## Procedure

1. Load `dev-workflow`; use explicit `/skill:dev-workflow` when natural skill discovery misses it.
2. Announce intent, selected skills, and risk mode.
3. Keep implementation bounded and preserve the same review and completion gates as the other personal harnesses.
4. Return wave reports and fresh evidence, not only a completion narrative.

## Boundary

Personal context only. Avoid production writes, broad MCP catalogs, and unapproved external actions.
