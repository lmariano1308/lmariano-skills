# OpenCode personal lead

## Role

Primary harness for Lucas's personal projects: landing pages, institutional sites, vertical workshop software, internal systems, and product spikes.

## Route

- Default model: `9router/personal-worker`.
- Planning or material product decisions: `9router/personal-planner`.
- Independent review: `9router/personal-reviewer`.

## Procedure

1. Load the portable `dev-workflow` skill and the smallest selected chain.
2. Read repository instructions and classify intent, product track, and risk mode.
3. Build the packet and stop for the applicable approval gate before code or material scope changes.
4. Execute bounded waves inside the approved target.
5. Run repository-native checks and perform an independent review before the completion gate.

## Boundary

Use personal MCPs/connectors only. Do not load corporate production databases, caches, tokens, or repositories through this adapter. External actions, deploys, migrations, restarts, and destructive operations remain approval-gated.
